### 📖 Sobre o Projeto

A **Durand Tech Systen** é especializada em soluções tecnológicas. Este site foi criado para ser nossa vitrine digital: apresentar serviços, gerar credibilidade e captar clientes em Pelotas e todo o Brasil.

**Foco do projeto:**
- Design clean, rápido e profissional
- Totalmente responsivo (Mobile First)
- Otimizado para SEO e conversão no WhatsApp

### 💻 Tecnologias

Projeto feito 100% com tecnologias base da web, sem frameworks pesados — garantindo máxima performance.

- **HTML5** — Estrutura semântica e acessível
- **CSS3** — Estilização moderna com Flexbox, Grid e animações
- **JavaScript (Vanilla)** — Interatividade, menu mobile e animações de scroll
- **Git & GitHub** — Versionamento
- **GitHub Pages + Domínio Personalizado** — Hospedagem

### 🌐 Deploy e Domínio Personalizado

O site está hospedado na Vercel / GitHub Pages e apontado para `www.durandtechsysten.com.br`.

Se estiver usando GitHub Pages, garanta:

1. Um arquivo `CNAME` na raiz com o conteúdo:
```
www.durandtechsysten.com.br
```
2. No painel do seu domínio (Registro.br / Hostinger etc), aponte:
```
Tipo A -> 185.199.108.153
Tipo A -> 185.199.109.153
Tipo A -> 185.199.110.153
Tipo A -> 185.199.111.153
CNAME www -> otaviostarkdev.github.io
```
3. Em `GitHub > Settings > Pages` marque `Enforce HTTPS`

Para atualizar o site:
```bash
git add .
git commit -m "feat: atualização"
git push origin main
```
