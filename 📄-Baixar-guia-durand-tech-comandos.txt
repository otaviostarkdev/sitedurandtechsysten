1. COMANDOS GIT - DEPLOY NA VERCEL PELO VS CODE
-------------------------------------------------
# Verifica o status dos arquivos
git status

# Adiciona um arquivo específico
git add index.html

# Adiciona TODOS os arquivos alterados
git add .

# Salva as alterações com uma mensagem
git commit -m "descreva o que voce fez aqui"

# Exemplos de mensagens boas:
git commit -m "remove secao orcamento da home"
git commit -m "fix favicon chrome v2"
git commit -m "atualiza valores condominager pro"

# Envia pro GitHub (a Vercel detecta e faz deploy automatico)
git push

# Se sua branch for main:
git push origin main

# Se sua branch for master:
git push origin master

# Puxa alterações do GitHub pro seu PC
git pull

# Ver historico de commits
git log --oneline

# Ver qual branch voce esta
git branch


2. COMANDOS DNS - PARA VERIFICAR SE O SITE PROPAGOU
----------------------------------------------------
# No CMD do Windows (Win + R -> cmd)

# Limpa o cache DNS do seu PC (quando da NXDOMAIN)
ipconfig /flushdns

# Ve para qual IP seu dominio esta apontando
nslookup durandtechsysten.com.br
nslookup www.durandtechsysten.com.br

# Ve com qual servidor DNS esta resolvendo
nslookup durandtechsysten.com.br 1.1.1.1
nslookup durandtechsysten.com.br 8.8.8.8

# Lista todo o cache DNS do seu PC
ipconfig /displaydns

# Forca abrir sem cache (no navegador anonimo):
# Ctrl + Shift + N (Chrome)
# E digite: https://durandtechsysten.com.br

4. COMANDOS VERCEL - DEPLOYMENT
--------------------------------
# Na aba Deployments da Vercel:
# Building = amarelo = esta subindo
# Ready = verde = site no ar
# Error = vermelho = deu erro, clica pra ver log

# Dominios:
# Valid = OK verde
# Invalid Configuration = vermelho = DNS errado
# Pending = aguardando propagar DNS
